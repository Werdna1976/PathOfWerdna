with no attribution required. The creators are credited here anyway.

| `samples/starninjas_sword/` | 20 Sword Sound Effects: attacks | StarNinjas | CC0 | https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes |

StarNinjas asks for a link to their OpenGameArt profile if you use the sounds:
https://opengameart.org/users/starninjas

Everything in `sfx/`, `music/` and `ambience/` is generated by `tools/gen_audio.gd`. Recipes replace every
generated sound effect except `potion_drink`, which still uses the generated one.
How the samples are layered into game sounds is set in `data/audio/recipes.json`.
